# Project Description

MeetExtract AI is an AI-powered meeting intelligence platform designed to transform unstructured meeting transcripts into structured, validated, explainable, and actionable work items.

The system analyzes meeting transcripts to identify commitments and action items, determine responsible owners, interpret deadlines, identify current status, assign confidence, and preserve supporting evidence from the original transcript.

Unlike a basic meeting summarization tool, MeetExtract AI focuses on converting conversations into accountable actions. Every AI-generated action passes through structured-output validation and intelligence-level checks before being presented as reliable application data. Uncertain, ambiguous, conflicting, or low-confidence results are identified and routed to a human review workflow rather than being blindly accepted.

The platform provides a complete workflow:

Ingest → Understand → Extract → Validate → Evaluate → Review → Finalize → Export → Measure

MeetExtract AI also includes an evaluation system that allows AI extraction quality to be measured against human-defined ground truth. It supports evaluation datasets, extraction runs, accuracy metrics, failure analysis, regression testing, and model/prompt comparisons.

The project is designed as a practical AI engineering system rather than a simple LLM wrapper. It combines AI-based information extraction with deterministic validation, evidence-based explainability, confidence assessment, human-in-the-loop review, analytics, and measurable evaluation.

The MVP supports TXT, PDF, DOCX, and direct-text transcript inputs and provides meeting management, action-item management, review workflows, analytics, evaluation, and CSV/JSON export.

The primary objective is to build a reliable and maintainable system that helps teams move from meeting conversations to clearly defined, accountable, and measurable actions.
